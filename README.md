# 🔐 Hycrypt 文件加密解密工具

一个基于现代密码学标准的安全文件加密解密工具，采用 AES-256-CBC 加密算法和 Argon2id 密钥派生函数。支持文件和目录加密，提供密码确认机制确保加密安全。

## ✨ 主要功能

- **双重操作模式**：支持交互式界面和命令行参数
- **安全加密**：采用业界标准的 AES-256-CBC 加密算法
- **强密钥派生**：使用 Argon2id (2015 年密码哈希比赛冠军)
- **智能文件命名**：解密后自动恢复原文件名，无多余后缀
- **目录加密**：支持目录压缩加密，自动处理多级子目录
- **密码确认**：加密时强制二次确认，防止密码输入错误
- **算法显示**：实时显示当前使用的加密算法信息
- **自定义输出**：支持指定加密/解密输出文件名
- **文件完整性**：自动处理文件大小和格式

## 🔬 程序原理

### 加密流程

1. **密钥派生**：使用 Argon2id 从用户密码派生 256 位加密密钥
2. **随机参数生成**：生成 128 位随机盐值和初始化向量 (IV)
3. **预处理检查**：如果是目录，先压缩为 ZIP 格式
4. **AES 加密**：使用 AES-256-CBC 模式对文件内容进行加密
5. **数据组装**：将盐值、IV 和密文组合成加密文件
6. **后处理**：清理临时压缩文件（目录加密时）

### 解密流程

1. **参数提取**：从加密文件中提取盐值、IV 和密文
2. **密钥重建**：使用相同的 Argon2id 参数重新派生解密密钥
3. **AES 解密**：使用 AES-256-CBC 模式解密密文
4. **数据恢复**：去除填充，恢复原始文件内容
5. **后处理**：如果是压缩文件，自动解压并恢复目录结构

### 安全设计

- **前向保密**：每次加密都使用随机盐值和 IV
- **密码验证**：通过解密结果自然验证密码正确性
- **密码确认**：加密时强制二次确认，防止密码输入错误
- **数据完整性**：PKCS#7 填充确保数据完整
- **无密码存储**：系统不存储用户密码，完全去中心化
- **算法透明**：实时显示使用的加密算法信息

## 🛡️ 算法优势

### AES-256-CBC 加密

- **密钥长度**：256 位，提供军事级安全强度
- **加密模式**：CBC (Cipher Block Chaining)，增强安全性
- **块大小**：128 位，符合工业标准
- **填充方案**：PKCS#7，确保数据完整性

### Argon2id 密钥派生

- **内存消耗**：64MB，抵御硬件攻击
- **时间成本**：10 次迭代，平衡安全性与性能
- **并行度**：4 线程，充分利用多核处理器
- **盐值**：128 位随机数，防止彩虹表攻击

## 🚀 快速开始

### 交互式界面

```bash
python encrypt.py
```

### 命令行加密

```bash
# 基本文件加密
python encrypt.py -e 文件.txt -p 密码

# 指定输出文件名
python encrypt.py -e 文件.txt -p 密码 -o 自定义名称.enc

# 目录加密（自动压缩）
python encrypt.py -e 目录路径 -p 密码
```

### 命令行解密

```bash
# 基本文件解密
python encrypt.py -d 文件.txt.enc -p 密码

# 指定输出文件名
python encrypt.py -d 文件.txt.enc -p 密码 -o 恢复文件.txt

# 目录解密（自动解压）
python encrypt.py -d 20250923-目录.zip.enc -p 密码
```

## 📋 文件管理规则

### 工作目录管理

- **用户文件**：加密/解密文件保持在原始目录位置
- **测试文件**：所有测试文件存放在 `__demo__` 目录
- **目录加密**：压缩文件生成在原始目录同级位置
- **命名格式**：目录加密采用 `YYYYMMDD-目录名.zip.enc` 格式

### 使用规范

- 用户加密文件直接输出到源文件目录
- 测试和演示文件统一放置在 `__demo__` 目录
- 临时压缩文件自动清理，保持目录整洁

## 🔒 安全说明

1. **密码强度**：建议密码长度不少于 6 位
2. **密码确认**：加密时强制二次确认，防止密码输入错误
3. **文件备份**：加密前请备份重要文件
4. **密码管理**：请妥善保管加密密码，遗忘密码无法恢复文件
5. **加密验证**：加密后请验证文件完整性
6. **算法透明**：实时显示使用的加密算法，确保安全性可见
