# 📁 文件管理规则

## 🎯 目标
确保所有程序生成的文件有序管理，避免工作目录混乱。

## 📋 基本规则

### 1. 工作目录限制
- **主程序** (`encrypt.py`) 和 **测试文件** 可以存在于根目录
- **所有生成的文件** 必须放入 `__demo__` 文件夹
- **临时文件** 必须在程序结束时清理

### 2. 文件分类管理

#### 🗂️ 演示目录 (`__demo__/`) 结构
```
__demo__/
├── test_files/          # 测试用例生成的文件
├── user_data/           # 用户演示数据
├── temp_archives/       # 临时压缩文件（自动清理）
└── encrypted_output/    # 加密结果文件
```

#### 📊 文件命名规范
- **测试文件**: `test_*.txt`, `test_*.enc`
- **压缩文件**: `20250923-目录名.zip`
- **加密文件**: `20250923-目录名.zip.enc`
- **解密文件**: 恢复原文件名

### 3. 程序行为规则

#### 🔒 加密流程
1. 文件加密：`test.txt` → `__demo__/test.txt.enc`
2. 目录加密：`目录/` → `__demo__/20250923-目录.zip.enc`

#### 🔓 解密流程
1. 文件解密：`__demo__/test.txt.enc` → `test.txt`
2. 目录解密：`__demo__/20250923-目录.zip.enc` → `目录/`

#### 🧹 清理规则
- 临时压缩文件：加密后立即清理
- 临时解密文件：解密后立即清理
- 测试残留文件：测试完成后清理

## 🚫 禁止行为
- ❌ 在工作目录根目录生成文件
- ❌ 遗留临时文件不清理
- ❌ 使用混乱的文件命名
- ❌ 混合用户数据和测试数据

## ✅ 最佳实践
- ✅ 所有输出文件放入指定目录
- ✅ 使用清晰的文件命名规范
- ✅ 及时清理临时文件
- ✅ 保持工作目录整洁

## 🔧 实施检查
程序应包含以下检查机制：
1. 文件生成前检查目标目录是否存在
2. 文件操作后验证文件完整性
3. 程序退出前清理临时文件
4. 错误处理时确保不遗留垃圾文件

---

**注意**: 违反这些规则可能导致工作目录混乱和文件管理困难。请严格遵守文件管理规则。
